# 数字2048 | 2048 Puzzle

一个简洁优雅的 2048 数字益智游戏，纯 HTML/CSS/JS 实现，无需任何依赖，打开即玩。

## 功能特点

- **纯前端实现** — 单个 HTML 文件，无需编译、无需安装
- **双语言支持** — 简体中文 / English 一键切换
- **分数记录** — 本地存储最高分（localStorage），刷新不丢失
- **全屏模式** — 沉浸式游戏体验
- **键盘 & 触屏** — 支持键盘方向键和移动端触屏滑动操作
- **自适应字号** — 大数字（≥1024）自动缩小字体，保证可读性
- **清新配色** — 青色（Cyan）渐变色彩方案，视觉舒适

## 游戏规则

- 使用方向键（↑ ↓ ← →）或滑动屏幕，使所有方块朝同一方向移动
- 两个相同数字的方块碰撞后会合并，数值翻倍
- 每次移动后，空白处会随机出现一个 2 或 4（90% 概率为 2）
- 拼出 **2048** 即获胜，之后可选择继续挑战更高分数
- 棋盘满且无法移动时游戏结束

## 使用方法

直接双击 `index.html` 在浏览器中打开即可开始游戏。

| 操作 | 方式 |
|------|------|
| 移动方块 | 键盘方向键 / 触屏滑动 |
| 新游戏 | 点击「新游戏」按钮 |
| 切换语言 | 点击左上角「中/EN」按钮 |
| 全屏模式 | 点击右上角「全屏」按钮 |

## 技术实现

- **Canvas 渲染** — 使用 HTML5 Canvas 绘制游戏棋盘和方块
- **圆角矩形** — 通过 `quadraticCurveTo` 手动绘制圆角路径
- **响应式字号** — 根据方块数值动态调整字体大小
- **localStorage** — 持久化最高分记录
- **Fullscreen API** — 浏览器原生全屏支持
- **触摸事件** — `touchstart` / `touchend` 计算滑动方向，阈值 20px

## 已知问题

| # | 问题 | 影响 |
|---|------|------|
| 1 | 胜利弹出覆盖层后，键盘/触屏仍可操作底层游戏 | 覆盖层遮挡时游戏仍在运行 |
| 2 | 胜利后继续玩到死局，覆盖层文本从"恭喜"变为"游戏结束" | 可能让用户困惑 |
| 3 | 全屏按钮文本"全屏"不随语言切换 | 英文界面下仍显示中文 |
| 4 | localStorage 异常时 `parseInt` 可能产生 NaN | 极低概率，不影响游戏 |
